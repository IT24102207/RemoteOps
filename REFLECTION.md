## 1. Overview

This assignment helped me understand the basic concepts of client-server programming using C and TCP sockets. I gained practical experience working in a Linux environment, compiling programs, organising project files, and using Git and GitHub.

## 2. What I Learned

I learned how a client communicates with a server through sockets and how commands and responses are exchanged between the controller and the agent. I also improved my understanding of authentication, command handling, logging, and project organisation.

Using CentOS helped me practise Linux terminal commands and troubleshoot common problems. Working with Git introduced me to version control, committing changes, and pushing files to a remote repository.

## 3. Challenges

One challenge was navigating directories and managing project files in CentOS. I learned to use commands such as `pwd`, `ls`, `cd`, and `mkdir` to locate and organise files.

Understanding the communication between the controller and agent also required careful testing. I learned that debugging is easier when I check one feature at a time and examine the actual output.

## 4. Testing and Verification

The application should be tested against the requirements in the assignment brief. Important checks include authentication, supported and unsupported commands, file transfer, monitoring, client disconnection, and log entries.

I will record the actual results of the tests I perform and include suitable evidence in my report. I will not describe a feature as successful unless I have verified its behaviour.

## 7. Conclusion

This assignment helped me develop practical skills in C programming, networking, Linux, debugging, and version control. I learned that completing a project involves more than writing code; it also requires systematic testing, accurate documentation, and evidence that the implementation meets the requirements.
